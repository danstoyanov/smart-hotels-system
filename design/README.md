# Design reference

The files in this folder are visual reference material that the owner supplied
for the website design (task SIN-64). They are **not part of the application**:
the app does not load, serve or import them.

- `DESIGN.md` — colour, typography and spacing tokens that inspired the site styles.
- `code.html` and `screen.png` — a mock-up exported from a design tool.

The mock-up loads images and scripts from remote addresses and contains invented
names, contact details and awards. None of this is a claim about a real hotel or
business. The real website is in `frontend/`, and its photographs are described in
[the SIN-64 asset notes](../docs/history/sin-64-assets.md).
