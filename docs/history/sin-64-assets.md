# SIN-64 visual assets

The design inputs in `design/` were supplied by the user for T07. They are reference material. The app uses its own HTML, CSS and browser JavaScript, with the existing FastAPI API and chat.

The three photographs in `frontend/assets/images/` were generated for this fictional hotel with the built-in imagegen tool on 24 October 2026. They are illustrative images, not photographs of a real hotel. No third-party stock images, remote image URLs or paid Gemini calls were used. The app shows only hotel facts from `hotel/` and the backend.

```text
Constraints: one fictional property; no people, no signs, no text, no logos, no watermark; do not imply pools or services.
```
