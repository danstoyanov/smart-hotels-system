# Fonts

The site serves its two fonts from this folder, so pages make no requests to
font services. These are the fonts named in `design/DESIGN.md`.

| File | Font | Source |
| --- | --- | --- |
| `playfair-display-latin-wght.woff2` | Playfair Display, variable weight, Latin | npm `@fontsource-variable/playfair-display@5.3.0` |
| `playfair-display-latin-wght-italic.woff2` | Playfair Display Italic, variable weight, Latin | npm `@fontsource-variable/playfair-display@5.3.0` |
| `manrope-latin-wght.woff2` | Manrope, variable weight, Latin | npm `@fontsource-variable/manrope@5.3.0` |

Both fonts are licensed under the SIL Open Font License 1.1; see
`OFL-playfair-display.txt` and `OFL-manrope.txt`. The files are unchanged. Only
the Latin subset is included because the guest pages are in English.
